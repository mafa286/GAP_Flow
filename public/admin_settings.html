2. System-Aktualisierung & Backup (Live-Verwaltung)

Laden Sie den aktuellen Stand des Programms (Backend-Logik, package.json-Abhängigkeiten und den vollständigen public/-Frontendordner) herunter, um lokale Anpassungen vorzunehmen, oder spielen Sie ein modifiziertes Update-ZIP-Paket ein. Der Server führt nach dem Upload automatisch ein npm install aus und startet sich neu.

Code herunterladen

Erstellt ein Live-ZIP-Backup mit der aktuellen server.ts, der package.json und dem vollständigen public/-Verzeichnis.

Update-ZIP hochladen

Wählen Sie ein geändertes ZIP-Paket aus. Nach dem Upload sichert der Server die Vorgängerversion als backup_previous.zip und startet sich neu.

System neustarten

Beendet den Serverprozess sofort kontrolliert. Docker startet den Container daraufhin automatisch neu (Dauer: ca. 5–10 Sek.).
